# QuietBoard
This is where I test out QuietBoard, my vibecoded textboard software. It's used for InfinityFree. To download it, uhh I don't know. Figure it out yourself.
After downloading it, put it in the files for your InfinityFree server, next go to config.php in your files and configure the options, then go to (yourdomain)/installer.php, create an admin account, then you're done.

Note that I won't update this often.

## Requirements

InfinityFree
